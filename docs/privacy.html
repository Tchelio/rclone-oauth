Privacy Policy

Last updated: October 20, 2026

This policy applies to a personal Google OAuth client configured for use with the open-source rclone tool, as described on the homepage.

What data is accessed

With the Google account owner's authorization, rclone may access Google Drive file and folder metadata, file content, and, if the user grants write access, may create, change, or delete Drive files. The exact access depends on the OAuth scopes selected in rclone.

How data is used

Google Drive data is processed by rclone only to perform the user's requested file operations, such as listing, downloading, uploading, or synchronizing files. This personal OAuth setup does not operate a separate cloud backend or sell Google user data.

Storage and sharing

OAuth access and refresh tokens are handled by rclone and are normally stored in the user's local rclone configuration. This static website does not receive tokens, Google Drive files, or account credentials. Files may be transferred to other storage destinations only when the user configures and initiates such operations in rclone. Google Drive data is not shared for advertising or marketing.

Retention and deletion

Files and local credentials remain subject to the user's own rclone and storage configuration. The user can delete local rclone credentials and revoke authorization at Google Account Connections. This static website does not maintain a separate user database.

Website hosting

This site uses GitHub Pages. It does not include tracking scripts or a data submission form. GitHub may process standard website access information according to its own policies.

Contact

For questions about this personal OAuth configuration, contact the repository owner through the GitHub profile.

Independent personal configuration; not affiliated with Google or the rclone project.
