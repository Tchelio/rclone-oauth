rclone - Privacy Policy

Last updated: October 21, 2026

This policy describes the personal Google OAuth application named rclone and its use with the open-source rclone command-line tool. It is maintained by the owner of this GitHub Pages site, not by Google or the official rclone project. See the application homepage.

What data is accessed

With the Google account owner's explicit OAuth authorization, the rclone tool may access Google Drive file and folder names, identifiers, sizes and other metadata, as well as file contents. If the owner selects a scope with write permissions, it may also create, change, move, and delete files or folders. Access is limited to the Google Drive permissions that the user approves in the consent screen.

How data is used

Google Drive data is used only to perform file operations initiated or configured by the account owner, such as browsing, copying, downloading, uploading, backing up, and synchronizing files. The static website does not collect, inspect, process, or store Google Drive files. This configuration does not use Google user data for advertising, marketing, profiling, or AI model training.

Storage and sharing

Google OAuth access and refresh tokens are handled by rclone and are normally stored in the user's local rclone configuration, under the user's control. The website does not receive these tokens, Google account passwords, or Drive data. The user is responsible for restricting access to their local configuration and any storage destinations they select. Files may be transferred to other storage providers only when the user explicitly configures rclone to perform those operations. This OAuth website does not sell, broker, or disclose Google user data to advertisers.

Retention and deletion

Local credentials remain stored for as long as the user keeps their rclone configuration; downloaded or transferred files remain wherever the user chose to store them until the user removes them. To stop access, the user can delete the rclone remote or its OAuth credentials and revoke the app at Google Account Connections. Revocation prevents further authorized API requests but does not automatically delete files the user previously transferred. This static website maintains no account database and retains no Google Drive data.

Website hosting

This site uses GitHub Pages. It does not include tracking scripts or a data submission form. GitHub may process standard website access information according to its own policies.

Contact

For questions about this personal OAuth configuration, contact the repository owner through the GitHub profile.

Independent personal configuration; not affiliated with Google or the rclone project.
