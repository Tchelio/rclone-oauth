Personal rclone Google Drive Connection

This page describes a personal Google OAuth client used to connect the open-source rclone tool to Google Drive accounts that the account owner explicitly authorizes.

The OAuth client is intended for private file management, including browsing and transferring files using rclone. It is not a hosted file-sharing service and this website does not provide a sign-in interface or receive OAuth credentials.

Google account access is granted only through Google's OAuth consent process. The permissions requested depend on the rclone configuration chosen by the user.

Read the privacy policy for details on Google data access, use, storage, and removal.

Independent personal configuration; not affiliated with Google or the rclone project.
