rclone

Personal Google Drive OAuth connection

This is the homepage for a personal Google OAuth application named rclone. It lets the account owner authorize the open-source rclone command-line tool to access Google Drive accounts the owner chooses.

The purpose is private file management: listing folders, reading file metadata, downloading files, uploading files, and synchronizing data when authorized. No Google Drive files are published by this website. Access to Google Drive is granted through Google's OAuth consent screen, using the scopes the user chooses when configuring rclone.

This static informational website has no sign-in page, does not receive Google OAuth credentials, and does not operate a separate file storage service. The rclone program runs under the user's control, not on this site.

Privacy: Read the privacy policy to learn what Google user data can be accessed, how it is used, how credentials are stored, and how access can be revoked.

Independent personal configuration; not affiliated with Google or the rclone project.
